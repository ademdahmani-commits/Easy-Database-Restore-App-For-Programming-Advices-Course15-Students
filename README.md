# Easy-Database-Restore-App-For-Programming-Advices-Course15-Students
Small WinForms Application that makes the restore of a Database more easier to the new students of Course 15
<h1 align="center">Database Backup Restorer</h1><p align="center">
  A simple tool to restore SQL Server databases from <code>.bak</code> files easily.
</p><hr><h2>💡 About</h2><p>
  Database Backup Restorer is a Windows Forms application built with C# and .NET Framework.
  It simplifies the process of restoring SQL Server database backups without manually
  going through SQL Server Management Studio.
</p><h2>✨ Features</h2><ul>
  <li>Select a SQL Server backup file (<code>.bak</code>).</li>
  <li>Choose a custom database name.</li>
  <li>Restore the database with a simple interface.</li>
</ul><h2>🛠️ Built With</h2><ul>
  <li>C#</li>
  <li>Windows Forms</li>
  <li>.NET Framework</li>
  <li>Microsoft SQL Server</li>
</ul><h2>🎯 Goal</h2><p>
  Make SQL Server database restoration faster, simpler, and more accessible for Course15 Students.
</p><h2>📋 Requirements</h2><ul>
  <li>Windows</li>
  <li>Microsoft SQL Server</li>
  <li>.NET Framework</li>
  <li>You Have to Copy The Database u have downloaded to the backup folder of ur Sql server</li>
</ul><h2>🚧 Important Notice </h2><p>This app works only on the local server of the course maybe i will make it support all servers later...</p>
